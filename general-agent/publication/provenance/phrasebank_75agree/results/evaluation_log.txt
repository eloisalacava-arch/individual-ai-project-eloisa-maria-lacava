== Method notes ==
- Confusion matrix orientation: rows = human reference, columns = AI.
- Accuracy and recall CIs: Wilson score. Kappa, balanced accuracy, precision and F1: seeded percentile bootstrap.
- The benchmark is a majority verdict at >=75% annotator agreement, not an adjudicated gold standard; per-annotator labels are not released, so human-human kappa is not computable and the published agreement is item-level, not kappa.
- Disagreements are not confirmed errors. Zero confirmed errors are estimable with this data; see t10_error_status.csv.
- Ordinal distance is a severity proxy (adjacent vs opposite), not evidence about which label is right.
- No causal claims: these are associations between predicted and reference labels on one unstratified sample from the 75% subset.
- 0 failed predictions in this run, so both abstention policies coincide; the exclusion is recorded in t01_join_and_sample.csv.
- Transparency: aggregate benchmark class counts were seen before classification (to report the sampling frame). No per-row reference value entered the prompt or the classifier, and this evaluation still freezes predictions before opening the benchmark.
